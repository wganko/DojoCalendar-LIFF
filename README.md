# DojoCalendar LIFF App

LIFF アプリケーション for 四国道場

## URLs

- 欠席連絡: https://wganko.github.io/DojoCalendar-LIFF/absence.html
- 一斉送信: https://wganko.github.io/DojoCalendar-LIFF/broadcast.html

## 説明

このリポジトリは、LINE LIFF アプリのエンドポイントをホストするために使用されます。

- `absence.html`: 欠席・遅刻連絡フォームへのリダイレクト
- `broadcast.html`: 管理者向け一斉送信 UI
